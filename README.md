# csc110_classactivity


In this activity, you have to debug a program given to you. It should run as a calculator, asking for user input and operations, and then computing their results. However, there are a LOT of issues with this code -- grammatical issues, bugs with conditionals and loops, and a lot of incorrect action words used. Your job is to fix it so the calculator will run.  

In addition to the issues within the code, there are also a lot of problems with the input. Remember, when there are no limits on user input, they can input anything. Make sure to limit user input (making sure they're putting in integers when needed, giving them options to pick from when necessary, etc).
